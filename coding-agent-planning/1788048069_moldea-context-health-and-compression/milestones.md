# Milestones: natural discovery, adoption, and context compression

The implementation should be decomposed because the portable skill and its behavioral evidence form one coherent source boundary, adapter qualification inputs form a second independently reviewable boundary, and fresh paid release evidence has separate commit, cost, and authorization prerequisites. The milestones below preserve the complete scope of `plan.md` without creating temporary compatibility paths, placeholder behavior, or deferred correctness work.
