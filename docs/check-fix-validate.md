# Check, fix, and validate project context

## Check alignment

Ask **Check the support agent's instruction wiring** for a read-only comparison of the canonical instruction and the actual model call. Check reports the assessed scope, confirmed drift, diagnostics and missing evidence. A valid format may coexist with a semantic mismatch. An ordinary unscoped code review does not start a full project audit.

## Fix a project

Ask **Fix moldea** or name the area you want fixed. The coding agent makes the smallest authorized correction when the governing claim is established. If two meaningful claims conflict, it identifies both and stops for your choice unless independent governing evidence resolves them.

A whole-project Fix begins with the bundled Git checkpoint helper. It inspects safe bounded Git evidence and never writes Git state. A helper limit, including an attribute filter or unavailable commit, can leave Git-dependent verification incomplete. The agent assesses owners progressively, reports checked and remaining scope, changed paths, checks and issues needing input, and offers numbered next choices. Continue in the same conversation from the reported full commit, next owner, uncommitted paths and manifest owner entries. The agent rechecks affected work and labels any stale assessments. After authorized correction it runs native checks and validates the final state.

An existing foundation can be repaired when prior adoption and the intended correction are established. Healthy state is left intact. The managed AGENTS.md block and governing Claude import follow host authority, with an exact handoff for protected files.

## Validate structure

Ask **Validate the moldea project** to run the bundled CLI read-only. Node.js runs the skill while the project can use any language. Validation checks declared files across languages and supported JavaScript and TypeScript ESM symbols. Unsupported symbols remain `not-checked`. The result reports structural errors, warnings, integration and checked bindings. A native connection test provides separate evidence for actual instruction or schema consumption.

A standalone Validate does not take a Fix checkpoint. A completed valid or invalid result establishes invocation. When adoption or execution blocks the check, the agent reports the bounded foundation evidence and the unverified check.

## Resolve a warning

You can authorize a correction or accept an eligible diagnostic with your reason. Integration warnings are eligible only for shared, Git-tracked AGENTS.md or CLAUDE.md instruction subjects. A local-only or ignored file gets a fix or exact handoff. Acceptance stores the reported code, subject and qualifier, and leaves errors and unchecked connections unchanged. Validate after adding or removing an acceptance.
