# Scripted journeys

The [recorded journeys](/evidence/journeys/) show how selected coding agents used moldea in isolated projects. Each result identifies the skill version, provider, and checks captured in that run. The [project runs](/evidence/project-runs/) preserve separate repository examples and observations.

These records describe their tested scenarios and releases. They do not establish current behavior across all coding agents or repositories.
