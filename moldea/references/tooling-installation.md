# Check local prerequisites

Use for explicit initialization or project repair. The installed skill includes the CLI and its dependencies. Check that Git and Node meet the supported contract in `local-tooling.md` and that the selected git working tree is accessible. Report a missing prerequisite before continuing. Host trust and execution restrictions apply to every command.

For initialization, continue into `continuous-maintenance.md` once the prerequisites are available. For repair, `project-repair.md` owns diagnosis and the authorized fix.
