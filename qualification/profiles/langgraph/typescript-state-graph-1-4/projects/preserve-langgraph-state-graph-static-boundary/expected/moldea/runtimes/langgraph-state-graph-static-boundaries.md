# LangGraph StateGraph static boundaries

The adapter can prove directly exported compiled graphs, closed direct schema bindings, and supported graph operations. Positive node and edge patterns do not prove a complete, reachable, or executable topology.

Runtime-selected conditional routes, `Command`, and `Send` destinations remain dynamic. Graph nodes and node-local calls do not become manifest tools, skills, handoffs, or subagents. Compiled descriptions do not establish supervisor routing.

Schema factories, reducers, node metadata, subgraphs, checkpointers, stores, caches, runtime context, prebuilt agents, `ToolNode`, and supervisor composition remain runtime-owned. Use direct immutable schema values in one closed modern initializer when input or output schema evidence must be canonical.
