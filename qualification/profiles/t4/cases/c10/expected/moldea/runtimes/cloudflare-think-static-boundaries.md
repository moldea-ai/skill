# Cloudflare Think static boundaries

`SupportAgent` uses an open `getTools()` map, so the final tool registration remains runtime-dependent. `StepSupportAgent` delegates session construction to a helper, so static inspection does not establish one instruction loader. `RuntimeInitializedAgent` has executable class initialization and remains outside the supported target.

Cloudflare bindings, Durable Object migrations, and deployment configuration remain project-local operational concerns outside these static source relationships.
