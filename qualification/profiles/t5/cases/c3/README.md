# Create a grounded agent

The seed is an adopted order-triage project with a concrete custom runtime factory and a runtime-owned instruction-loader boundary, but no registered agent. The expected state registers exactly one agent and documents how that boundary supplies its canonical instruction to the implementation.

The expected fixture uses `moldea/runtimes/custom.md` as one valid dry-run result. Official actors may choose another descriptive Markdown path under `moldea/runtimes/`; the manifest reference and grounded content are authoritative, not the filename.

This case catches generic agent prose, missing or duplicate runtime guidance, fabricated bindings, unrelated changes, and identifiers that disagree across canonical and executable surfaces.
